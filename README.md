Monte Carlo Tic-Tac-Toe

## Project Description
This project implements a Tic-Tac-Toe game using Monte Carlo Tree Search (MCTS).

## Features
- Selection
- Expansion
- Simulation
- Backpropagation
- MCTS-based Tic-Tac-Toe agent
- Comparison with Minimax algorithm

## How MCTS Works
MCTS uses random game simulations to find promising moves without building the complete game tree.

## Technologies Used
- Python
- Monte Carlo Tree Search
- Minimax Algorithm

## How to Run
Run the following command:

python main.py
