TEST CASES - MONTE CARLO TIC-TAC-TOE

Test Case 1: Start Game
Input: 5
Expected Output: The player's O is placed at position 5.

Test Case 2: Valid Move
Input: 1
Expected Output: The player can place O at position 1.

Test Case 3: Invalid Move
Input: An already occupied position
Expected Output: "Position already occupied."

Test Case 4: Invalid Input
Input: A letter or number outside 1-9
Expected Output: "Please enter a valid number."

Test Case 5: MCTS Move
Input: A valid player move
Expected Output: MCTS selects an available position for X.

Test Case 6: Player Wins
Input: Three O marks in a winning combination
Expected Output: "You Win!"

Test Case 7: MCTS Wins
Input: Three X marks in a winning combination
Expected Output: "MCTS Agent Wins!"

Test Case 8: Draw
Input: Board filled without a winning combination
Expected Output: "Game Draw!"

Test Case 9: MCTS vs Minimax
Input: Empty board
Expected Output: Program displays the positions selected by MCTS and Minimax.
